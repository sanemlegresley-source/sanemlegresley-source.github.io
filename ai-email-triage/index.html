Project 01

Email triage prototype

A small in-browser sketch of an LLM-assisted triage layer: it reads a message, assigns priority, category and sentiment, routes it to the right queue, and drafts a first-pass reply — the idea being that a team touches only what genuinely needs a person. It runs entirely in your browser.

    How it works in production

    1 · Classify

    A structured prompt sends each message to an LLM that returns strict JSON — category, priority, sentiment, entities, and a confidence score — validated against a schema before anything downstream trusts it.

    2 · Route

    Deterministic rules act on the model's output: high-confidence, low-risk mail is auto-routed and acknowledged; anything ambiguous or high-stakes is escalated to a human with the model's reasoning attached.

    3 · Draft & learn

    The model drafts a reply grounded in a knowledge base; agents edit rather than write. Every human correction is logged and folded back into evaluation sets, so accuracy compounds.

    Stack & principles: LLM classification with schema-validated JSON output · human-in-the-loop escalation on low confidence · offline-deterministic demo (the classifier on this page is a transparent rule model so it runs with no API key) · privacy-first: content never leaves the browser here.
